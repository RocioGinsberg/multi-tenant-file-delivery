# RFC

RFC 用于记录还在评审或刚落地的技术方案。方案稳定后，关键结论应沉淀到 `docs/ADR/`。

## 状态

| 状态 | 含义 |
|---|---|
| Draft | 草案 |
| Accepted | 已采用 |
| Superseded | 被新 RFC / ADR 替代 |
